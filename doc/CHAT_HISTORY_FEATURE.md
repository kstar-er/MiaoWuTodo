# AI 对话历史记录功能实现

## 功能概述

在 AI 对话窗口的左侧增加了对话历史记录面板，用户可以管理和切换不同轮次的对话记录。

## 核心功能

### 1. 对话历史面板（左侧边栏）
- **位置**：对话模式下，窗口左侧显示历史记录面板
- **宽度**：250px 固定宽度
- **内容**：
  - 对话历史列表
  - 新建对话按钮
  - 清空历史按钮

### 2. 对话会话管理

#### 创建新对话
- 点击"+ 新建对话"按钮创建新会话
- 新会话自动成为当前活跃会话
- 初始标题为"对话 N"（N为序号）

#### 切换对话
- 点击历史列表中的任意对话项切换
- 当前活跃对话高亮显示（棕色背景）
- 切换后立即显示该对话的所有消息

#### 删除对话
- 每个对话项右侧有删除按钮（✕）
- 点击删除后需要确认
- 删除后自动切换到其他对话

#### 清空所有历史
- 点击历史面板顶部的清空按钮（🗑️）
- 需要二次确认
- 清空后自动创建一个新的空对话

### 3. 对话标题自动生成
- 第一条用户消息发送后，自动使用该消息的前30个字符作为对话标题
- 超过30字符的部分用"..."表示
- 标题用于快速识别对话内容

### 4. 数据持久化
- 所有对话历史保存到浏览器 localStorage
- 键名：`ai_chat_history`
- 包含内容：
  - 会话 ID
  - 会话标题
  - 创建时间戳
  - 所有消息记录

### 5. 数据结构

#### 会话对象
```javascript
{
  id: number,              // 时间戳作为唯一ID
  title: string,           // 对话标题
  timestamp: string,       // 创建时间（格式：YYYY-MM-DD HH:MM:SS）
  messages: Array          // 消息数组
}
```

#### 消息对象
```javascript
{
  role: 'user' | 'assistant',  // 消息角色
  content: string              // 消息内容
}
```

### 历史面板样式
- **背景色**：#fff9f5（浅米色）
- **边框**：1px solid #d9bfb8（棕色边框）
- **活跃项背景**：#8b4513（棕色）
- **活跃项文字**：#fffcfa（浅色）

### 交互反馈
- 悬停效果：背景色变浅
- 删除按钮：悬停时显示
- 新建对话按钮：点击时有下沉动画

## 使用流程

1. **初次使用**
   - 应用启动时自动创建第一个空对话
   - 用户可以开始输入消息

2. **发送消息**
   - 消息自动添加到当前会话
   - 第一条消息发送后，自动生成对话标题
   - 历史自动保存

3. **切换对话**
   - 点击左侧历史列表中的对话项
   - 消息区域立即显示该对话的内容

4. **管理历史**
   - 删除不需要的对话
   - 清空所有历史重新开始
   - 历史数据持久化保存

## 浏览器兼容性

- 依赖 localStorage API
- 支持所有现代浏览器
- 数据存储大小限制：通常 5-10MB

## 注意事项

1. **数据安全**
   - 历史数据存储在本地浏览器
   - 不涉及服务器存储
   - 清除浏览器数据会丢失历史

2. **性能考虑**
   - 大量对话时可能影响性能
   - 建议定期清理旧对话
   - 单个对话消息数量无限制

3. **用户体验**
   - 对话标题自动生成，便于识别
   - 删除操作需要确认，防止误删
   - 清空操作需要二次确认
