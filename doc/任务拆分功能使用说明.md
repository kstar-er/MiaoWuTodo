# 任务拆分功能使用说明

## 功能概述

任务拆分功能允许用户将复杂的任务自动拆分为多个子任务，提高任务管理的效率和细粒度。系统支持两种拆分方式：

1. **规则拆分**：基于数字标题格式自动识别
2. **AI拆分**：通过人工智能分析任务内容（待实现）

## 使用方法

### 1. 创建可拆分的任务

在任务详情中使用数字标题格式，例如：

```
完成网站开发项目

1. 需求分析
   分析用户需求和业务流程，确定功能范围

2. 系统设计  
   设计系统架构、数据库结构和接口规范

3. 前端开发
   实现用户界面和交互功能

4. 后端开发
   开发API接口和业务逻辑

5. 测试部署
   进行功能测试和系统部署
```

### 2. 拆分任务

1. 保存任务后，在任务详情页面会显示"拆分"按钮（橙色齿轮图标）
2. 点击拆分按钮，系统会自动分析任务内容
3. 如果检测到可拆分的内容，会显示拆分预览弹窗
4. 确认拆分后，系统会自动创建子任务

### 3. 拆分结果

- 每个数字标题会成为一个独立的子任务
- 子任务会继承父任务的基本信息（项目、负责人等）
- 子任务与父任务建立关联关系

## 支持的标题格式

系统支持以下数字标题格式：

- `1. 标题内容`
- `2、标题内容`  
- `3：标题内容`
- `4: 标题内容`

## 注意事项

1. 只有已保存的任务才能进行拆分
2. 至少需要2个数字标题才能进行拆分
3. 拆分后的子任务可以独立管理和跟踪
4. 建议在任务描述中提供详细的步骤说明

## 技术实现

### 后端接口

- `POST /taskSplit/analyze/{taskId}` - 分析任务是否可拆分
- `POST /taskSplit/confirm` - 确认拆分并创建子任务

### 前端组件

- `TaskSplitDialog.vue` - 拆分结果展示弹窗
- 在 `taskDetail.vue` 中集成拆分按钮和逻辑

### 规则引擎

使用正则表达式识别数字标题格式：
```java
Pattern.compile("(?:^|\\n)\\s*([1-9]\\d*)[.、：:]\\s*([^\\n]+)(?:\\n([^\\n1-9]*(?:\\n(?!\\s*[1-9]\\d*[.、：:])[^\\n]*)*))?", Pattern.MULTILINE)
```
