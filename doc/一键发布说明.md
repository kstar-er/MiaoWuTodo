# 一键发布说明

## 本地发布

使用当前 `package.json` 里的版本号发布：

```powershell
npm run release
```

指定版本号发布：

```powershell
npm run release -- -Version 1.1.8
```

默认行为：

- 同步 `package.json`、`package-lock.json`、`src-tauri/tauri.conf.json` 的版本号
- 提交版本文件
- 创建 `v版本号` tag
- 推送 `main` 和 tag 到 `origin`
- 如果存在 `gitee` remote，同时推送 `main` 和 tag 到 Gitee

如果你的 GitHub 远端不是 `origin`：

```powershell
npm run release -- -GithubRemote github
```

只创建本地提交和 tag，不推送：

```powershell
npm run release -- -NoPush
```

默认要求工作区是干净的。如果你确定要把当前所有未提交改动一起打进发布提交：

```powershell
npm run release -- -CommitAll
```

## GitHub Secrets

GitHub Actions 上传 OSS 需要配置这些 Secrets：

- `ALI_OSS_ACCESS_KEY_ID`
- `ALI_OSS_ACCESS_KEY_SECRET`
- `ALI_OSS_BUCKET`
- `ALI_OSS_REGION`

可选：

- `ALI_OSS_ENDPOINT`
- `ALI_OSS_STS_TOKEN`
- `ALI_OSS_OBJECT_KEY`，默认是 `latest.json`

Gitee Release 同步继续使用已有的：

- `GITEE_TOKEN`

## 更新清单流程

tag 触发 GitHub Actions 后：

1. GitHub 打包并生成 Release 资产
2. 同步 GitHub Release 到 Gitee
3. 下载 GitHub Release 里的 `latest.json`
4. 把里面的 GitHub Release 下载地址替换为 Gitee Release 下载地址
5. 上传替换后的 `latest.json` 到 OSS
