# AI对话功能快速开始指南

## 功能概览

AI对话功能为宠物应用提供了两种工作模式：

### 🗨️ 对话模式
- 与AI进行自由对话
- 提问、咨询、讨论
- 实时消息交互

### ✏️ 编辑模式
- AI协作编辑文档
- 生成修改预览（diff）
- 版本管理和回滚

## 快速开始

### 第一步：打开AI对话窗口

1. 右键点击桌面宠物
2. 在菜单中选择 **"AI对话"**
3. AI对话窗口将打开

### 第二步：选择工作模式

#### 对话模式
```
1. 点击顶部 "对话模式" 按钮
2. 在输入框输入您的问题
3. 按 Ctrl+Enter 或点击 "发送" 按钮
4. 等待AI回复
```

#### 编辑模式
```
1. 点击顶部 "编辑模式" 按钮
2. 点击 "浏览" 按钮选择要编辑的文件
3. 在 "编辑指令" 框输入编辑要求
4. 点击 "应用修改" 按钮
5. 查看修改预览
6. 点击 "确认修改" 或 "拒绝修改"
```

## 使用示例

### 对话模式示例

**用户**: "请解释什么是闭包"
**AI**: "闭包是一个函数与其周围状态（词法环境）的组合。..."

### 编辑模式示例

**场景**: 优化一段代码注释

1. 选择文件: `example.js`
2. 编辑指令: "请改进这段代码的注释，使其更清晰"
3. AI返回修改预览
4. 确认修改后，文件自动保存

## 版本管理

### 查看版本历史
- 在编辑模式下，右侧显示 "版本历史"
- 每个版本显示：版本号、时间、修改摘要

### 回滚到之前的版本
```
1. 在版本历史中找到要回滚的版本
2. 点击该版本的 "回滚" 按钮
3. 文件内容将恢复到该版本
4. 回滚操作本身也会生成新版本
```

## 配置API

### 必要配置
在使用AI功能前，需要配置以下信息：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| API端点 | AI服务的API URL | `https://api.openai.com/v1/chat/completions` |
| 模型 | 使用的AI模型 | `gpt-4` 或 `gpt-3.5-turbo` |
| API密钥 | 认证密钥（可选） | `sk-...` |

### 配置方式
配置信息存储在浏览器localStorage中：
- `ai_endpoint`: API端点
- `ai_model`: 模型名称
- `ai_api_key`: API密钥

## 常见问题

### Q: 如何修改API配置？
A: 配置信息存储在localStorage中。您可以通过浏览器开发者工具修改，或等待后续版本的设置界面。

### Q: 版本历史会保存多久？
A: 版本历史仅在当前会话中保留。刷新或关闭窗口后会丢失。建议定期保存重要版本。

### Q: 编辑模式支持哪些修改操作？
A: 当前支持 `replace` 操作（替换文本）。后续版本将支持 `insert` 和 `delete` 操作。

### Q: 如何确保修改不会丢失？
A: 
1. 确认修改前会显示预览
2. 修改后自动保存到文件
3. 版本历史可用于回滚

### Q: 能否同时编辑多个文件？
A: 当前版本支持单文件编辑。多文件编辑功能将在后续版本中支持。

## 工作流示例

### 场景：优化周报文档

```
1. 打开AI对话窗口
2. 切换到编辑模式
3. 选择周报文件 (report.md)
4. 输入指令: "请改进这份周报的表述，使其更专业"
5. 查看AI生成的修改预览
6. 确认修改
7. 文件自动保存

```

### 场景：代码审查讨论

```
1. 打开AI对话窗口
2. 切换到对话模式
3. 提问: "这段代码有什么性能问题吗？"
4. 获取AI分析
5. 继续提问: "如何优化？"
6. 获取优化建议
```

## 提示和技巧

💡 **对话模式技巧**
- 提供充分的上下文信息
- 使用清晰的问题表述
- 可以进行多轮对话

💡 **编辑模式技巧**
- 编辑指令要具体明确
- 先查看修改预览再确认
- 定期检查版本历史

💡 **性能优化**
- 大文件编辑可能需要更长时间
- 建议将大文件分割成小部分编辑
